## Legenda gerada

Todo mundo fala de Claude Code como ferramenta de programador. Faz sentido — a interface é um terminal, os exemplos são de código, o nome tem "Code" no título.

Mas nos últimos 3 meses, a ferramenta que mais mudou como eu opero minha agência não foi nenhum software de gestão. Foi o Claude Code.

Não pra programar. Pra operar.

Hoje uso pra redigir proposta comercial completa em 12 minutos — com diagnóstico, escopo e precificação. Pra montar relatório de performance com interpretação estratégica, não só números. Pra criar SOP de processo interno que qualquer pessoa da equipe consegue seguir sem precisar me perguntar. Pra automatizar o briefing de novo cliente — o agente lê o site, analisa o mercado, estrutura os primeiros 30 dias.

Isso não é código. É operação.

A diferença entre quem usa IA como calculadora e quem usa como sistema operacional é exatamente essa: um resolve uma tarefa, o outro muda como o negócio funciona.

No carrossel, mostro o fluxo real — do briefing ao relatório, passando por proposta e SOP. Tudo sem programar uma linha.

Se você tem agência ou presta serviço e ainda não virou Claude Code pro lado da operação, você tá deixando pelo menos 3 horas por semana na mesa.

Qual parte da sua operação você automatizaria primeiro?

## Como publicar manualmente

1. Puxe o repo localmente: `git pull`
2. Copie o `.env` do `ccos-env` para a raiz
3. Instale dependências: `npm install`
4. Rode: `node scripts/gerar-e-publicar.mjs 1`

O script vai regenerar os slides e publicar em todas as redes.
